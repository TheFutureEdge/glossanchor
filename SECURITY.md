# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Reporting

Please use GitHub private vulnerability reporting for
`TheFutureEdge/glossanchor`. Do not open a public issue for a suspected
vulnerability or include secrets, proprietary data, or exploit details in a
public Discussion.

GlossAnchor makes no network or storage calls. Reports should include the
affected version, minimal synthetic reproduction, impact, and suggested
mitigation when known.
