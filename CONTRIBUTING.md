# Contributing

Thank you for helping improve GlossAnchor.

1. Open or reference an issue for behavioral changes.
2. Keep each pull request focused and use synthetic fixtures only.
3. Run `npm ci` and `npm run verify` on Node.js 20 or newer.
4. Add tests for every public behavior and preserve the separate bundle budgets.
5. Do not include private, employer, customer, or product-specific code or data.

AI-assisted contributions are welcome when they comply with these rules. The
contributor remains responsible for understanding the change, reviewing every
submitted line, testing it, disclosing assistance when relevant, and responding
to review feedback.
