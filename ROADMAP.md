# Roadmap

## 0.1

Ship the minimal stable matcher, React renderer, interaction enhancer, grouped
glossary helpers, documentation, tests, and Next.js example.

## Later candidates

- optional adapters for additional UI frameworks;
- position-aware popover primitives without imposing a styling system;
- benchmarks for very large dictionaries and documents;
- additional accessibility examples based on maintainer and user feedback.

Roadmap items are not commitments. Backward compatibility and package weight
take priority over feature count.
